# SmartBlind — 화면 위 이름 블라인드 (macOS · NAVER WORKS용)

**NAVER WORKS**(및 지정한 다른 앱)에서 **등록한 사람의 이름(글자)** 이 보이면, 그 사람의 **프로필·이름·메시지·알림**을 실시간으로 가립니다.
얼굴 인식이 아니라 **텍스트로 된 이름**을 찾습니다. 메신저를 수정하지 않고, 화면 위에 투명한 가림막 창을 덧씌우는 방식입니다.

> 대화창에서는 대상의 프로필·이름·사진·버튼·말풍선·시간까지 가리고, 바로 아래 **내 메시지와 다른 사람은 가리지 않습니다.**
> 기본 스타일은 **강한 블러**입니다: 큰 칸 모자이크로 형태를 먼저 지우고 → 강하게 흐린 뒤 → 대비를 낮추고 → 메신저 배경색 반투명 막(최대 75%)을 덮어, 사진도 윤곽까지 거의 보이지 않습니다.

## 1. 설치 (처음 한 번)

필요한 것: **macOS 14(Sonoma) 이상**, Xcode 또는 Command Line Tools (`xcode-select --install`)

1. `SmartBlind_빌드_및_설치.command` 더블클릭
   (차단되면 우클릭 → 열기)
2. 빌드가 끝나면 `~/Applications/SmartBlind.app`이 설치되고 실행됩니다. 메뉴 막대에 눈 아이콘이 생깁니다.
3. 권한 두 개를 켜세요 (시스템 설정 → 개인정보 보호 및 보안):
   - **화면 및 시스템 오디오 녹음** → SmartBlind 켜기 (화면 글자 인식, 모자이크/블러)
   - **손쉬운 사용** → SmartBlind 켜기 (메신저 텍스트 읽기, 가림막 클릭 처리)
4. 권한을 켠 뒤 SmartBlind를 **종료했다가 다시 실행**하세요.
5. **NAVER WORKS는 자동 등록**됩니다 (설치된 앱/실행 중인 앱을 이름으로 찾아 감시 앱 맨 위에 추가).
   메뉴 막대에 "NAVER WORKS가 등록되지 않았어요"가 보이면 NAVER WORKS를 실행한 뒤 **찾기**를 누르세요.
   (설정 → 앱별 범위 → "NAVER WORKS 찾아서 등록"도 같은 기능)
6. 설정 → **대상**에서 가릴 사람 이름을 추가하면 바로 동작합니다.

터미널: `./build.sh` (빌드만) · `./build.sh install` (설치·실행) · `./build.sh test` (핵심 로직 테스트)

## 2. 사용

| 설정 탭 | 내용 |
|---|---|
| **대상** | 가릴 사람 추가 · 이름/별칭(쉼표 구분) · 사람별 ON/OFF · 적용할 앱 |
| **블라인드** | 모자이크 / 블러 / 단색 / 이미지, 강도, 모서리, 여백, 클릭 공개 시간(3·5·10초·직접 닫기) |
| **인식** | 인식 빈도(빠름/균형/절약), 이름 일치 방식, 접근성 우선 / OCR 보조, 노출 방지 옵션 |
| **앱별 범위** | NAVER WORKS 자동 등록/찾기, 다른 앱 추가(실행 중인 앱 목록), 앱별 가림 범위, 앱 자체 토스트 감시, macOS 알림 배너 |
| **상태** | 감시 중인 앱, 감지한 대상 수, 권한 상태, 일시정지, 로그인 시 실행 |

- **가림막 클릭** → 잠깐 보기. 다시 클릭하거나 시간이 지나면 다시 가려집니다. 보는 중에도 위치 추적은 계속됩니다.
- **Option + 클릭** → 가림막을 통과해 메신저에 원래 클릭으로 전달 (가린 채로 사진 열기 등)
- **스크롤·드래그**는 가림막 위에서도 그대로 메신저에 전달됩니다.

## 3. 어떻게 찾고 어디까지 가리나

### 이름 찾기
1. **접근성(Accessibility) 정보** — 앱이 제공하면 가장 빠르고 정확 (Slack·Teams 같은 Electron 앱은 자동으로 켜서 읽음)
2. **화면 OCR (Apple Vision, 한국어+영어)** — 접근성 정보를 주지 않는 화면(대화 내용 등)
3. 이름 일치 방식
   - **단어 일치(기본)**: `홍길동`, `홍길동님`, `홍길동[회사]`, `홍길동이`는 찾고 `홍길동수`, `hong1234`는 건너뜀. OCR이 `홍 길동`처럼 띄어 읽어도 찾음
   - **포함**: 글자 안에 들어 있으면 찾음
   - **포함 + 오인식 허용**: OCR이 한 글자를 잘못 읽어도(효→호) 찾음 (비슷한 이름의 다른 사람도 걸릴 수 있음)

### 가림 범위 (자동)
| 상황 | 가리는 범위 |
|---|---|
| 대화창 | 프로필 사진 + 이름 + 이어지는 말풍선·사진·이모티콘·버튼·시간. **다음 사람 프로필, 내 메시지(오른쪽 정렬), 가운데 날짜 구분선**이 나오면 멈춤 |
| 친구·채팅 목록 | 프로필 + 이름 + 상태메시지/미리보기 한 줄 (창 끝까지) |
| 단체방 미리보기 `홍길동: 메시지` | 그 미리보기 줄 |
| **macOS 알림 배너** | 그 알림 카드 전체 (여러 알림이 쌓여도 해당 카드만) |
| **메신저 자체 토스트/작은 알림 창** | 그 창 전체 |
| 다른 사람 글 본문에 이름이 언급됨 | 이름 글자만 (옵션으로 끌 수 있음) |
| 구조를 판단할 수 없음 (예: 제목 표시줄) | **이름만** (관련 없는 사람을 가리지 않도록 보수적으로) |

자동 판단이 맞지 않는 앱은 **앱별 범위**에서 `이름만 / 이름+프로필 / 목록 한 줄 / 직접 지정(이름 기준 상하좌우 확장)`으로 바꿀 수 있습니다.

### 노출 방지 · 위치 추적
- 창마다 ScreenCaptureKit으로 **그 창만** 캡처 → 화면이 안 바뀌면 프레임이 오지 않아 OCR도 쉼
- **스크롤 예측**: OCR이 끝나기 전에 행 단위 비교로 스크롤 양을 계산해 가림막을 먼저 옮김
- **새 알림·토스트는 확인될 때까지 먼저 가림** (0.1~0.5초) → 대상이 아니면 바로 풀림
- 화면이 바뀌었는데 이름이 사라지면 가림막 **즉시 제거** (화면 그대로인데 OCR이 한 번 놓친 경우만 잠시 유지)
- 창 이동·크기 변경은 창 기준 좌표로 따라가고(움직일 땐 60Hz), **다른 창에 가려진 부분은 가림막을 잘라냄** → 엉뚱한 앱 위에 남지 않음
- Spaces 전환·전체 화면·최소화·다중 모니터·Retina 배율 대응
- 새 메시지가 아래에 추가되는 등 일부만 바뀌면 **바뀐 띠만 OCR**

## 4. 알아 두기

- **권한 초기화**: 기본은 임시(ad-hoc) 서명이라 **다시 빌드하면 macOS가 권한을 다시 물을 수 있습니다.**
  유지하려면 키체인 접근 → 인증서 지원 → 인증서 생성 → 이름 `SmartBlind Dev`, 유형 `코드 서명`으로 만든 뒤 다시 빌드하세요 (build.sh가 자동으로 사용).
- macOS 15 이상에서는 화면 캡처를 쓰는 앱에 보라색 녹화 표시가 뜨고, 주기적으로 "계속 허용" 확인이 나올 수 있습니다.
- OCR 한계: 아주 작은 글씨, 이름을 이미지로 그린 경우, 프로필 사진 없이 이름만 있는 UI는 이름만 가립니다. 이 경우 앱별 범위를 "직접 지정"으로 조정하세요.
- 접근성 권한이 없으면 가림막 클릭은 되지만 Option+클릭 전달과 접근성 인식은 동작하지 않습니다.
- 설정 파일: `~/Library/Application Support/SmartBlind/settings.json` (상태 탭 → 설정 파일 보기)
- 카카오톡·Slack·Teams·LINE은 목록에 꺼진 상태로 들어 있습니다. 필요하면 켜서 쓰세요.
- NAVER WORKS 알림이 macOS 알림 배너로 뜨면 "macOS 알림 배너" 옵션으로, NAVER WORKS 자체 팝업 창으로 뜨면 "앱 자체 알림(토스트) 감시" 옵션으로 가려집니다 (둘 다 기본 켜짐).
